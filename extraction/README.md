# Source extraction index

This directory makes the source chain discoverable without inventing a transcript that is not present in the repository.

- `source_index.yaml` records the fixed shared-conversation fingerprint, decoded extent, integrated Google document, current machine authority, and present development-conversation evidence.
- `lexicon/completed_atoms_source.md` preserves the source-developed atomic records used directly by the language.
- `docs/SOURCE_PROVENANCE.md` explains precedence and the relationship between human and machine authority.
- `spec/source_provenance.yaml` is the machine-readable provenance manifest.

The current Codex development conversation is private and has no stable public transcript URL. Its user-directed decisions are preserved in the files and Git history named above; they are not misrepresented as a verbatim public ledger.
