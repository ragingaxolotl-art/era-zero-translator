## Next work within the first two selected priorities

1. Correct misleading gap guidance. Both workers and Three workers currently misclassify workers as a missing verb. Very heavy needs degree grammar. Still absent needs continuation/ordinal handling. Remain/remained already have indexed uses; their unavailable constructions should not simply be labeled new words. Preserve genuine requests to define glimmerwise or zorbled.
2. Add reusable quantity and modifier scope: contextually given pairs, cardinality, restrictive only, degree, ordinal descriptions and continuing states. Do not silently drop these words or invent numeric thresholds. These needs concern structure as well as vocabulary.
3. Extend relationships and attachment: until endpoints, beside placement, reduced clauses such as before deleting, and longer noun descriptions. Preserve event order and which object each phrase describes.
4. Extend mental and social meanings through reviewed reuse or compounds: caused fear, knowledge/belief of a proposition, promises with future content, retained memory versus recalling, and preservation without imposing a future identity. A nearby English alias is not enough to establish these meanings.
5. Expand combinations among already supported profiles. Plain happy and sad sentences work, while some requirement/adjective combinations still do not. Support must be tested across new participants, negatives, questions and runtime 0/1/2, rather than only on one example.

The original musical style, vocabulary, compounds and runtime states remain reusable. Newly needed distinctions should first reuse an exact existing meaning, then a composition, then a conventional compound, then an explicit grammar extension. General recorded-audio decoding remains outside this shorter completion pass. Passing the implementation suite or one narrow release is not a reason to call the full translator complete.
