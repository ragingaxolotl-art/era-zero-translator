# Information saving and retained-state descriptions — November 23, 2026

This increment extends reusable verbs and ordinary sentence composition. It does not complete unrestricted English translation or recorded-audio decoding.

## Meaning and reuse

Save/saves/saved/saving and information-sense store/stores/stored/storing now refer to an actor committing a target information item's content to a retained record. The definition permits an existing record and unchanged content. Saving does not silently become copying, transformation, cross-context transfer, remembering, rescue, thrift or a guarantee of permanent retention.

The dependency order is existing DAT:000 retained information → completed retention commitment (convention 90) → productive actor causing that commitment (convention 91). No root was added. Stored as an adjective reuses DAT:000's exact published definition. A stored state does not assert that a saving event occurred.

Stored works as a state predicate, participant description and keep/stay/remain condition. Save/store work with supported participants, tense, ongoing aspect, ordered negation/modality, questions, commands, references, alternatives and related clauses. A game, box or other ambiguous label still needs an information-versus-other choice. Personal words named stored retain their separate meaning choice.

A description asserting retained information during its removal needs an explicit phase. “Nora deleted the stored file” therefore asks for a before/after clause; “The file was stored before Nora deleted it” preserves the same referent and the stated temporal relationship. The guard also follows roots through nested personal compounds and validates the recovered score. It does not assign an unstated phase.
