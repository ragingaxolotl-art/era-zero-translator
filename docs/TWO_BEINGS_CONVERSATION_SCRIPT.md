# Two-Beings Conversation: “The File Migration”

Oca uses the ocarina voice. Orin uses the warm-organ voice. The voices change
presentation timbre only; every pitch and canonical target remains unchanged.

**Oca:** Hello, I need the file inside the folder.

**Orin:** I found the file.

**Oca:** Please send the file to me.

**Orin:** We need to migrate the file.

**Oca:** The file is migrating.

**Orin:** We migrated the file.

The machine-readable script is `examples/two_beings_conversation.json`. Each
turn records the ordered canonical targets used by the performance. English
function words and participant pronouns guide interpretation but do not receive
invented atomic roots.

The included MP3 is a noncanonical presentation artifact. Its stereo position,
instrument timbre, loudness, and encoding do not alter the canonical notes or
semantic identities.
