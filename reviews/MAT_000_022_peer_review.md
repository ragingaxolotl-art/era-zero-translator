# MAT:000–022 Adversarial Semantic Peer Review

Status: **READY FOR USER APPROVAL — NOT CANONICAL**

Scope is strictly `MAT:000–022`. The nine current Phase 2 titles are treated as replaceable candidates. All deterministic generated fields remain fixed. The review uses only the fixed architecture and the 45 canonical LIF/MOV roots as semantic authority; it does not depend on the unapproved `MOV:200–222` recommendations.

## Executive recommendation

The strongest Matter entity-layer architecture is one scope grid with one phase grid:

- `MAT:000–002`: **focal material substrate** — persistent / physically active / dormant;
- `MAT:010–012`: **distinct external material object** — stable / physically active / dormant;
- `MAT:020–022`: **material aggregate** — stable / physically active / dormant.

This removes integrity, targethood, tool use, access, circulation, reserve purpose, topology, and future process/capacity meanings from the atoms. Those concepts remain expressible through later roots, grammar, or compounds.
