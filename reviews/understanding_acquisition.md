# Coming to understand: reusable acquisition construction

This draft binds the existing ORI:110 completed transition to the existing
comprehension result. It adds no root or comprehension sense. The same result
reference supplies the experiencer, content anchor, selected reading and source
restriction at each phase: before, the selected comprehension state does not hold;
at culmination it holds; later retention is unspecified. This is a completed
transition, not an ongoing attempt or merely attending to/receiving information.

The result document must be positive and have no independent matrix time scope.
It is evaluated at culmination, not asserted again at speech time. Event negation,
time and question speech act remain outside that result binding. Content-source
time stays inside the content: a past spoken source is not copied onto the
understanding state. Transition and result runtime 0/1/2 remain independent of
lexical completion, temporal placement and truth.

The English entry point accepts came-to-understand, did-not-come-to-understand
(including didn't) and Did questions over supported understanding contents.
Existing reading choices and pronoun bindings are reused. Unsupported result
syntax rejects before UI routing; no incomplete result is treated as translated.
This does not alias ordinary learned-the-route, learned-how, began-to-understand,
or factive learned-that into this narrower construction.

Music reuses existing understanding events, result-binding frames, temporal and
negation scopes and ORI:110. An opt-in comprehension-acquisition wrapper uses ±36.
The existing four knowledge-acquisition frames remain the default inventory;
all original paths and knowledge inverses are unchanged. Collision checks cover
ordinary grammar, other drafts, contextual content and speech-source frames.

Evidence: 27 combinations of event/result runtime and assertion/negated past/
question recover meaning from MIDI alone and match independent Ruby regeneration.
Existing 18 knowledge-acquisition parity cases still pass. Actual UI handlers
compose, play-schedule and export the new full acquisition document/MIDI. One
negated clean synthetic WAV recovers the full meaning without source English or
IR supplied to the decoder. No physical recording or simulated channel robustness
is claimed for this new case. Live UI/listening and canonical admission remain open.
