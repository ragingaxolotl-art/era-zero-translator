# Route learning: three draft result contracts

“Nora learned the route” does not uniquely specify memorized information,
practical navigation knowledge, or familiarity. Composition requires an explicit
selection. The selected result is acquired through the existing ORI:110 completed
transition: it did not hold before, holds at culmination, and has unspecified
later persistence. Negation and questions concern the transition, not a separate
assertion that its result holds now. Event and result runtime trits are independent.

Existing MIN persistent/current representation, representational revision and
attention roots do not entail recall, practical knowledge or acquaintance. A
revision can be erroneous; attention can occur without learning. Their definitions
remain unchanged. Three candidate result contracts use reserved foundation codes
4–6, following the existing desire, preference, knowledge and comprehension drafts.
These are not admitted roots or approved compounds. Before admission, generalize
and audit reusable memory, procedural knowledge and familiarity predicates across
other targets; avoid permanently making a separate lexical item for every noun.
No new 27-root family is justified by this implementation.

Music reuses participant roles, noun/name phonemes, nominal reference modes,
runtime markers, temporal/negative scopes, result binding and ORI:110. The draft
route-acquisition wrapper uses ±37. Explicit frame collision checks preserve the
default four acquisition frames. Shared blind dispatch accepts this profile only
with draft opt-in and demands one unique interpretation.

three readings, event/result trits, positive past, negated past and questions.

proximal and distal references. Source English, expected notes and meaning metadata
