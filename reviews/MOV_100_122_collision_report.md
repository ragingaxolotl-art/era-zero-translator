# MOV:100–122 Cross-Family Collision Report

Status: **PROVISIONAL — PENDING DETAILED SEMANTIC REVIEW**. This report proposes boundaries; it does not canonize any Motion meaning.

A pure displacement/traversal graph may use the proposed MOV root by itself. When another domain is independently asserted, form a compound. The MOV root must never consume the other family's process merely because English uses a motion metaphor.

## Findings

- The source triplet is safe only when **displacement away from a source** is present; release, withdrawal, deletion, and emergence are not automatically Motion.
- The target triplet is safe only when **displacement toward/reaching a target** is present; delivery, contact, instantiation, and manifestation remain other-family processes.
- The systemic triplet is safe only when **ordered route traversal** is present; generic system flow or transition would collide with nearly every process family.
- Cross-domain cases should be graphs/compounds, not broadened atomic definitions.
