# Physical width and the existing contextual adjective profile

This author review extends the user's translator-completion work. It does not create a root family or change an approved root/compound. The existing `EZCONTEXTUAL-1` profile already binds a selected physical dimension, a local adjective standard and one material bearer. Physical **wide** and **narrow** belong in that mechanism, alongside the existing mass, temperature, luminance and surface-texture interpretations.

Width here is the material bearer's lateral spatial extent along a contextually selected transverse axis, at a contextually selected section if the shape requires one. The axis and section are local contextual parameters, not unspoken measured values. Wide exceeds the local wide standard; narrow falls below the local narrow standard. Neither adjective is the negation of the other. An intermediate width may satisfy neither; the two standards need not be identical. A change in axis or section can change the judgment without contradiction.

`MAT:000` or `MAT:010` identifies the same physical bearer as before. Neither root alone entails width. `STR:010` is an engagement boundary, not a width measurement, and a spatial configuration alone does not select a transverse dimension or a comparison criterion. Creating an arbitrary compound from those nearby roots would add the wrong commitments. Reuse the existing comparison grammar instead, with an explicit `physical_width` dimension and two appended norm codes: wide 8, narrow 9. The eight earlier norm codes and their sounds remain unchanged.

The selected meaning concerns the object's physical extent. Clear width through an opening, passability, capacity, area, height, length, thickness, viewpoint-dependent apparent width, focus of attention and figurative breadth are separate interpretations. A gate's physical width does not by itself state how much room there is to pass through it. The UI must ask for the physical interpretation before composing the sentence; a noun's sound label supplies no ontology or measurement.

Time, negation, uncertainty, speech act and runtime 0/1/2 retain their existing independent scopes. Negated wide does not become narrow, runtime 2 does not become narrow, and two local standards do not establish an object-to-object comparison. This extension does not implement numerical width, wider/narrower comparisons, very/too, constrained aperture width or width-modified noun phrases. Unsupported details remain unresolved.

The dictionary should also expose the eight existing contextual adjective routes as structural meanings, so an unavailable construction is not mistaken for a missing adjective. Their admitted definitions must match the existing profile; adding these lookup records does not claim their other senses or any new grammar. All prior sense records remain unchanged.
